# 社内勤怠・有給管理アプリ 引継ぎ書

## 1. システム概要

PHP 8.2以上とMySQL/MariaDBで動く社内向けWebアプリです。公開ディレクトリは `public/`、アプリ本体は `src/`、画面は `views/`、DDLは `database/`、定期処理は `scripts/` にあります。依存関係はComposerで管理します。

重要な設定は `.env` にあります。実値や秘密鍵を文書・Gitへ転記しないでください。特に `DB_PASS`、Chatworkトークン、VAPID秘密鍵は引継ぎ時に安全な経路で管理者を変更します。

## 2. リリース手順

1. DBとアプリファイルをバックアップします。
2. ステージングまたはローカルでテストを実行します。
3. アプリファイルを配置します。`.env` と `storage/` は上書きしません。
4. `database/migrations/` の未適用SQLをファイル名順に適用します。
5. 画面のログイン、打刻、社員管理、有給残数、メール送信をスモークテストします。

既存環境でIPログを削除するリリースでは、次を実行します。このSQLは `audit_logs.ip_address` と既存値を削除するため、必要なバックアップを取得してから適用します。

```bash
php scripts/run-migration.php 20260909_remove_audit_ip_address.sql
```

## 3. 定期処理

XServerのCron例です。実際のPHPと配置先パスに置き換えます。

```cron
0 2 * * * /usr/bin/php /home/account/app/scripts/maintenance.php
10 2 * * * /usr/bin/php /home/account/app/scripts/accrue-leave.php
*/5 * * * * /usr/bin/php /home/account/app/scripts/push-reminders.php
```

- `maintenance.php`：取得日を過ぎた休暇の状態更新、期限切れトークン削除
- `accrue-leave.php`：入社日と有給更新月に基づく有給の冪等な自動付与
- `push-reminders.php`：社員設定に応じた退勤忘れWeb Push

Cronの標準出力・標準エラーは非公開ログへ保存し、容量と失敗を定期確認します。

## 4. メールと通知

招待・パスワード再設定メールはPHPの `mail()` を使用し、送信元は `MAIL_FROM` と `MAIL_FROM_NAME` です。本番ドメインのSPF/DKIM/DMARCとXServerの送信ログを確認してください。管理者によるパスワード再設定は、対象者の全セッションを即時失効してから60分有効のメールを発行します。

有給失効警告はメールやPushではなく、本人のホームと休暇画面に表示するアプリ内通知です。更新日の60日前から、予定反映後の前年繰越残数が正の場合に表示されます。

## 5. セキュリティ運用

- `public/` だけをWeb公開し、`.env`、`src/`、`database/`、`scripts/`、`vendor/` を直接公開しません。
- HTTPS、Secure/HttpOnly/SameSite Cookie、XServer WAF、日次バックアップを維持します。
- 操作履歴には操作者、操作、対象、変更前後、時刻を保存します。IPアドレスは取得・保存しません。
- 個別の端末紛失は社員一覧の「強制ログアウト」、広範な漏えい疑いは「全員をログアウト」を使用します。一括実行した管理者自身もログアウトします。
- 管理者のパスワード再設定メールは、対象者本人への連絡と宛先確認後に実行します。

## 6. バックアップと復旧

最低限、DB全体、`.env`、アップロードを追加した場合の保存領域をバックアップします。復旧訓練では、別DBへのリストア、管理者ログイン、残数、打刻、監査ログ、メール設定を確認します。保存済みIPは削除マイグレーション後にはDBから復元できません。

## 7. テストと確認コマンド

PHP実行ファイルがPATHにない場合は、XAMPPのPHPを指定します。

```powershell
node tests/static-check.mjs
& 'C:\xampp\php\php.exe' tests/password-mail-test.php
& 'C:\xampp\php\php.exe' tests/access-test.php
& 'C:\xampp\php\php.exe' tests/comp-auto-grant-test.php
& 'C:\xampp\php\php.exe' tests/leave-accrual-test.php
& 'C:\xampp\php\php.exe' tests/leave-import-service-test.php
```

リリース前は全PHPファイルの構文検査も実施します。

## 8. 既知の範囲外

休憩・残業・遅刻早退の自動計算、締め処理・月次確定、会社固有の繰越規則は未実装です。仕様を確定してからDB・集計・CSV・画面を同時に変更してください。

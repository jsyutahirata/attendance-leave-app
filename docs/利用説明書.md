# 社内勤怠・有給管理アプリ 利用説明書

## 1. ログインと初期設定

会社から届く招待メールのURLを開き、24時間以内にパスワードを設定します。通常の再設定メールは60分間有効です。URLは1回だけ使用できます。

ログイン後の「設定」では、表示テーマ、退勤忘れ通知、二要素認証を変更できます。共用端末では「ログイン状態を保持する」を使わず、利用後に必ずログアウトしてください。

## 2. 出勤・退勤

ホームまたは「出退勤」画面のボタンを押します。

- 出勤前は緑色の「出勤」ボタンです。
- 出勤中はオレンジ色の「退勤」ボタンです。
- 二重打刻はできません。誤打刻は管理者へ連絡してください。
- 土日の出勤打刻では、同じ日について代休1日が自動付与されます。

## 3. 有給・代休・勤怠連絡

「休暇・勤怠連絡」の「＋ 予定を登録」、またはカレンダーの日付を選択して登録します。有給は1日・午前休・午後休から選択できます。承認機能が有効な場合、有給は管理者の承認後に確定します。

有給は今年付与分から先に消化します。次の有給更新日まで60日以内となり、予定を反映しても前年繰越が残る場合は、ホームと休暇画面に失効予定日数を表示します。表示された日数は更新日になくなる見込みのため、取得予定を確認してください。

## 4. パスワードを忘れた場合

ログイン画面の「パスワードを忘れた方」から登録メールアドレスを入力します。メールが届かない場合は迷惑メールフォルダを確認し、管理者へ連絡してください。

管理者から再設定を実行された場合は、セキュリティ保護のため、その時点で対象アカウントの全端末がログアウトします。

## 5. 管理者の主な操作

### 社員管理

- 「社員を追加」でアカウントを作成し、招待メールを送信します。
- 社員一覧の「パスワード再設定」で、対象者を全端末からログアウトし、60分有効の再設定メールを送信します。
- 「強制ログアウト」は対象社員だけを全端末からログアウトします。
- 「全員をログアウト」は実行した管理者自身を含む全アカウントを全端末からログアウトします。認証情報の漏えいが疑われる場合など、緊急時に使用します。
- 無効化したアカウントはログインできません。休職中は所属・閲覧権限を保持します。

### 有給管理

残数の確認、手動付与、調整、代理登録、取消、承認・却下、CSVインポートを行えます。付与や調整の理由は、後から操作履歴で確認できる内容にしてください。

### 操作履歴

重要操作の日時、操作者、対象、変更前後を確認できます。接続元IPアドレスは取得・保存しません。

## 6. 困ったとき

- 画面が更新されない場合：再読み込みし、再ログインします。
- 通知が届かない場合：「設定」で通知許可と通知時刻を確認します。
- 招待・再設定メールが届かない場合：管理者は送信元設定とサーバーのメールログを確認します。
- 残数や打刻が違う場合：自己判断で重ねて登録せず、管理者へ対象日と内容を伝えます。
